# js-01-introducao
Notas de aula sobre introdução a JavaScript

## 📚 Conteúdo

Este repositório contém um tutorial completo para iniciantes sobre JavaScript, cobrindo:

### 📖 Tutorial Principal
- **História e Evolução do JavaScript** - De 1995 até hoje
- **Onde JavaScript é Utilizado** - Frontend, Backend, Mobile, Desktop, IoT, IA, Games
- **Variações e Transpiladores** - TypeScript, CoffeeScript, Babel, Dart, Elm, ReasonML, ClojureScript
- **Interpretadores e Motores** - V8, SpiderMonkey, JavaScriptCore, Node.js, Deno, Bun
- **Sintaxe Básica Completa:**
  - Variáveis: var, let, const (com ênfase nas diferenças)
  - Tipos: string, number, boolean, null, undefined, object, array
  - Operadores: aritméticos, relacionais, lógicos
  - Template literals e concatenação
  - Console.log para debugging

### 💻 Exemplos Práticos
O diretório `exemplos/` contém 5 arquivos JavaScript executáveis com exemplos práticos:
- `01-variaveis.js` - Variáveis e escopos
- `02-tipos-de-dados.js` - Todos os tipos de dados
- `03-operadores.js` - Operadores completos
- `04-template-literals.js` - Template literals e strings
- `05-console-debugging.js` - Console e técnicas de debugging

## 🚀 Como Usar

### Ler o Tutorial
```bash
# Abra o arquivo tutorial.md no seu editor ou navegador
cat tutorial.md
```

### Executar os Exemplos
```bash
# Certifique-se de ter o Node.js instalado
node --version

# Execute cada exemplo
node exemplos/01-variaveis.js
node exemplos/02-tipos-de-dados.js
node exemplos/03-operadores.js
node exemplos/04-template-literals.js
node exemplos/05-console-debugging.js
```

### Usar no Navegador
1. Abra o navegador (Chrome, Firefox, Edge, Safari)
2. Pressione F12 para abrir DevTools
3. Vá para a aba Console
4. Copie e cole qualquer código dos exemplos
5. Pressione Enter para executar
